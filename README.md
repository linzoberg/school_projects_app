Мобильное приложение для автоматизации учёта и сопровождения проектной деятельности школьников в образовательных организациях.

Разработано в рамках выпускной квалификационной работы.

---

## 🎯 Назначение

Приложение решает задачу централизованного хранения и управления школьными проектами. Педагоги, методисты и ученики получают единый мобильный инструмент для работы с проектной документацией в любое время и в любом месте.

**Проблема:** сведения о проектах хранятся разрозненно — в личных папках учителей, на флеш-носителях, в разных облачных сервисах. Это затрудняет отчётность, поиск нужной работы и отслеживание достижений учеников.

**Решение:** единое мобильное приложение с каталогом проектов, сквозной навигацией, поиском, гибкой фильтрацией, интерактивным календарём мероприятий и встроенной аналитикой.

---

## ✨ Функциональность

### 🔐 Авторизация и ролевая модель
- Регистрация и вход через **Firebase Authentication**.
- **Скрытая регистрация администраторов** по защищенному секретному коду доступа с валидацией.
- Три роли с динамическим и строгим разграничением прав:
    - **Ученик** — просмотр каталога, управление профилем и доступ к проектам, в которых он является участником.
    - **Руководитель / Преподаватель** — создание проектов, управление мероприятиями. Права на редактирование данных и загрузку ссылок на файлы ограничены только теми проектами, где Руководитель является создателем. Доступно удаление собственных созданных проектов.
    - **Администратор** — полный доступ ко всем модулям системы, администрирование базы данных проектов и мероприятий.

### 📂 Каталог и управление проектами
- Информативная карточка (паспорт) проекта со сквозной навигацией со всех экранов (Проекты, Календарь, Отчёт, Профиль).
- Полный набор метаданных: название, описание, направление, статус, сроки, организация, руководитель, участники, результаты и награды.
- **Жизненный цикл из 5 статусов:** Идея → В разработке → Завершён → На конкурсе → Архив.
- **8 тематических направлений:** Техническое, Естественно-научное, Гуманитарное, Социальное, Художественное, Математическое, Экологическое, Иное.

### 🔍 Поиск, сортировка и фильтрация
- Полнотекстовый поиск в реальном времени по названию, описанию, руководителю и школе.
- Оптимизированная система фильтрации и выбора элементов.
- Отображение активных фильтров в виде компактных интерактивных компонентов с возможностью мгновенного сброса параметров.

### 📎 Файлы и материалы
- Прикрепление ссылок на внешние облачные хранилища (Google Drive, Яндекс.Диск и др.) с фиксацией метаданных (имя, тип, дата добавления).
- Автоматическое распознавание типа файла по расширению и запуск во внешнем браузере в один тап.
- Доступ к добавлению файлов строго валидируется правами роли.

### 📅 Интерактивный календарь мероприятий
- Визуальная сетка месяца с локализацией (русские именительные названия месяцев) и поддержкой отображения нескольких индикаторов (событийных точек) на один день.
- Классификация событий: Олимпиада, Конкурс, Защита проектов, Выездное мероприятие, Другое.
- **Расширенные временные рамки:** поддержка многодневных событий и точного времени проведения.
- **Связь сущностей:** возможность прикрепления нескольких проектов к одному конкретному событию с возможностью быстрого перехода в карточку проекта прямо из экрана деталей события.
- Функция быстрого вызова полного списка «Все события месяца».

### 📊 Отчёты и интерактивная аналитика
- **Интерактивная статистика:** наглядное распределение данных по статусам, направлениям и школам с графическими полосами индикации. Строки статистики кликабельны — по тапу открывается шторка со списком соответствующих проектов.
- **Выборка:** панель детальной фильтрации проектов по организациям, направлениям, текущим статусам и временным диапазонам.

### 👤 Профиль пользователя
- Карточка пользователя с аватаром, ролью, возможностью смены отображаемого имени.
- Персонализированный динамический список проектов пользователя с автоматическим обновлением данных при возвращении с экранов деталей.
