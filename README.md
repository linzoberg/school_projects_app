Мобильное приложение для автоматизации учёта и сопровождения
проектной деятельности школьников в образовательных организациях.

Разработано в рамках выпускной квалификационной работы

---

## 🎯 Назначение

Приложение решает задачу централизованного хранения и управления
школьными проектами. Педагоги, методисты и ученики получают единый
мобильный инструмент для работы с проектной документацией
в любое время и в любом месте.

**Проблема:** сведения о проектах хранятся разрозненно —
в личных папках учителей, на флеш-носителях, в разных облачных
сервисах. Это затрудняет отчётность, поиск нужной работы
и отслеживание достижений учеников.

**Решение:** единое мобильное приложение с каталогом проектов,
поиском, фильтрацией, календарём мероприятий и аналитикой.

---

## ✨ Функциональность

### 🔐 Авторизация и роли
- Регистрация и вход через Firebase Authentication
- Три роли с разными правами доступа:
    - **Ученик** — просмотр каталога, своих проектов
    - **Руководитель** — создание и редактирование проектов,
      управление мероприятиями
    - **Администратор** — полный доступ, отчёты, управление данными

### 📂 Каталог проектов
- Карточка (паспорт) проекта с полным набором полей:
  название, описание, направление, статус, сроки,
  школа, руководитель, участники, результаты, награды
- Пять статусов: Идея → В разработке → Завершён →
  На конкурсе → Архив
- Восемь тематических направлений:
  Техническое, Естественно-научное, Гуманитарное,
  Социальное, Художественное, Математическое,
  Экологическое, Иное

### 🔍 Поиск и фильтрация
- Полнотекстовый поиск по названию, описанию,
  руководителю, школе
- Фильтрация по направлению и статусу
- Активные фильтры отображаются как чипы с возможностью
  быстрого сброса

### 👥 Участники
- Добавление участников из базы зарегистрированных пользователей
- Поиск по имени и email в диалоге выбора
- Возможность добавить участника вручную

### 📎 Файлы и материалы
- Прикрепление ссылок на файлы (Google Drive, Яндекс.Диск и др.)
- Хранение метаданных: имя файла, тип, дата добавления
- Открытие файла в браузере одним нажатием
- Автоматическое определение типа файла по расширению

### 📅 Календарь мероприятий
- Визуальная сетка месяца с отметками на днях с событиями
- Типы мероприятий: Олимпиада, Конкурс, Защита проектов,
  Выездное мероприятие, Другое
- Создание, редактирование и удаление мероприятий
- Фильтрация по выбранному дню

### 📊 Отчёты и аналитика
- **Статистика:** общее число проектов, распределение
  по статусам, направлениям и школам с визуальными полосами
- **Выборка:** гибкая фильтрация проектов по статусу,
  направлению, организации и периоду дат

### 👤 Профиль
- Карточка пользователя с аватаром, именем и ролью
- Список своих проектов (где является автором или участником)
- Редактирование отображаемого имени
- Выход из аккаунта
