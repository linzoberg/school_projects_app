# ПроектУМ (project PUMA)
[![Current Version](https://img.shields.io/badge/Version-0.4.1-green)](#)

Мобильное приложение для управления проектами школьников.

Основная цель приложения — предоставить удобный инструмент для организации проектной деятельности учащихся, планирования задач и отслеживания прогресса, упростить взаимодействие в рамках совместной работы и помочь грамотно распределять время.

### Ключевые возможности (в разработке)
* Создание и ведение учебных проектов.
* Распределение задач внутри команды и контроль дедлайнов.
* Мониторинг статуса выполнения задач (To Do, In Progress, Done).
* Интуитивно понятный мобильный интерфейс.

### Технологии и инструменты
* **Фреймворк:** Flutter
* **Язык программирования:** Dart
* **Среда разработки:** Android Studio
* **Целевые платформы:** Android

## 📱 Основной функционал

*   🔐 **Авторизация и безопасность:** Регистрация и вход пользователей с разграничением ролей на базе *Firebase Authentication*.
*   📂 **Управление проектами:** Создание карточек проектов, хранение описаний, целей и этапов выполнения.
*   💾 **Облачное хранилище данных:** Реализована синхронизация в реальном времени с базами данных *Cloud Firestore*.
*   📎 **Работа с файлами:** Возможность прикреплять к проектам необходимые учебные материалы и документы благодаря `file_picker`.
*   🌐 **Интеграция ресурсов:** Быстрый переход по внешним ссылкам и веб-ресурсам проекта через `url_launcher`.

## 📦 Спецификация сборки (Android)

Для корректной сборки проекта под современные требования Google Play и совместимости с новейшими плагинами, конфигурация среды была обновлена:

*   **минимальная версия SDK (minSdkVersion):** Зависит от используемого Flutter SDK
*   **версия компиляции (compileSdkVersion):** `36` (Android 15+)
*   **целевая версия (targetSdkVersion):** `36`
*   **Java/Kotlin compatibility:** JDK 17
